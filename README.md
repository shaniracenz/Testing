# C# MVC Project

This is a C# MVC project initialized using `dotnet new mvc`.

## Project Structure

- **/WebAppMvc/Controllers**: Contains controller classes that handle user requests.
- **/WebAppMvc/Models**: Contains model classes for application data and business logic.
- **/WebAppMvc/Views**: Contains Razor view files for the user interface.
- **/WebAppMvc/wwwroot**: Contains static files like CSS, JavaScript, and images.
- **WebAppMvc/Program.cs**: The main entry point for the application (contains the `Main` method and web host configuration).
- **WebAppMvc/WebAppMvc.csproj**: The project file containing build configurations and dependencies.

## Getting Started

To run this project:
1. Ensure you have the .NET SDK installed.
2. Navigate to the `WebAppMvc` directory.
3. Run `dotnet run`.
